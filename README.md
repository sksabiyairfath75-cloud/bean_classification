# bean_classification

This project uses Machine Learning to classify different types of dry beans based on their physical features.

## Dataset
The dataset contains measurements of dry bean characteristics such as area, perimeter, major axis length, minor axis length, roundness, and other features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning
The project includes:
- Data preprocessing
- Exploratory Data Analysis
- Feature scaling
- Model training
- Model evaluation
- Bean classification

## Files
- `b.ipynb` - Complete Jupyter Notebook
- `dry_bean_dataset.csv` - Dataset
- `bean_dry_bean_model.pkl` - Trained ML model
- `requirements.txt` - Required Python libraries

## Result
The trained machine learning model is used to classify dry bean varieties based on their features.
